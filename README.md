# LP Especial 11.11 – Olavo Manipulação

Landing page de captação de leads (acesso antecipado / Grupo VIP) para o Especial 11.11.

## Publicar no GitHub Pages

1. Crie um repositório novo no GitHub (ex.: `olavo-11-11`).
2. Envie os arquivos desta pasta (`index.html`, `.nojekyll`, `README.md`) para a branch `main`.
3. No repositório: **Settings > Pages > Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: **main** / pasta **/ (root)** → Save
4. Em 1–2 minutos a página fica disponível em `https://SEU-USUARIO.github.io/olavo-11-11/`.

### Domínio próprio (opcional)
Em **Settings > Pages > Custom domain**, informe o subdomínio (ex.: `1111.olavomanipulacao.com.br`) e crie um registro **CNAME** no DNS apontando para `SEU-USUARIO.github.io`.
